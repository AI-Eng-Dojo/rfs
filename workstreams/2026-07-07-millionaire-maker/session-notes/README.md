# Session Notes

グリル、調査、レビューのチェックポイントを一セッション一ファイルで保存します。

## ファイル名

```text
YYYY-MM-DD-short-topic.md
```

同日に複数回ある場合は、時刻または連番を追加します。

```text
2026-08-18-01-target-user.md
2026-08-18-02-first-product.md
```

## 記録ルール

- 生の会話ログをそのまま貼らず、再開に必要な内容を要約する。
- 採用済みの判断、暫定案、未解決事項を明確に分ける。
- 最後に扱った質問と、次に聞く質問を必ず残す。
- 外部セッションへのリンクだけに依存せず、重要な根拠を短く記録する。
- 個人情報、顧客情報、機密情報を含めない。
- セッションノートだけで判断を確定せず、採用時は `../decision-log.md` も更新する。

新規作成には [_template.md](_template.md) を使用してください。
